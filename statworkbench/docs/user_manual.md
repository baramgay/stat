# StatWorkbench 사용자 매뉴얼

버전 2.0.0 | 2026-05-19

## 1. 소개

### 1.1 제품 개요

StatWorkbench는 연구자, 의료 전문가, 공공기관 데이터 담당자가 코드 작성 없이 통계 분석을 수행할 수 있도록 설계된 **메뉴 기반 데스크톱 통계 패키지**입니다. SPSS의 직관적인 인터페이스와 Python 생태계의 최신 통계 라이브러리를 결합하여, 전문적인 통계 결과를 손쉽게 얻을 수 있습니다.

메뉴와 대화 상자를 통해 분석 옵션을 선택하면 StatWorkbench가 내부적으로 적절한 통계 검정을 수행하고, 구조화된 결과표와 해석 가이드를 결과 창에 출력합니다. 모든 분석 과정은 구문(Syntax) 로그로 자동 저장되므로 분석 재현성이 보장됩니다.

### 1.2 주요 특징

- **메뉴 기반 인터페이스**: 코드 없이 마우스와 키보드만으로 모든 분석 수행
- **한글 완벽 지원**: 변수명, 값 라벨, 결과 출력 전반에서 한글 표시 지원
- **Light / Dark 테마**: 업무 환경에 맞춰 테마 전환 가능 (Ctrl+Shift+D)
- **SPSS 호환 워크플로**: Data View, Variable View, 결과 창의 3분할 구성
- **변수 중심 설계**: 각 변수에 측정 척도, 값 라벨, 결측 규칙 등 메타데이터를 부여하여 분석 오류 방지
- **재현 가능한 분석**: 구문 로그가 자동 생성되어 동일 분석을 언제든 반복 실행 가능
- **다양한 분석 지원**: 기술통계부터 생존분석, 판별분석까지 20종 이상의 통계 기법 내장

[그림: StatWorkbench 메인 화면 전체 구성]

## 2. 시작하기

### 2.1 설치 방법

**방법 1 — pip 설치 (권장)**

```bash
pip install -e ".[dev]"
python -m statworkbench
```

**방법 2 — 배치 파일 실행**

프로젝트 루트 폴더에서 `run.bat`를 더블 클릭하면 가상환경을 자동으로 설정하고 프로그램을 시작합니다. Windows 환경에서 Python 설정이 익숙하지 않은 사용자에게 권장하는 방식입니다.

**방법 3 — 독립 실행 파일 (.exe)**

배포용 빌드를 사용하는 경우 `dist\StatWorkbench\StatWorkbench.exe`를 직접 실행합니다. 별도의 Python 설치가 필요하지 않습니다.

### 2.2 화면 구성 설명

StatWorkbench의 메인 화면은 크게 네 영역으로 구성됩니다.

[그림: 메인 화면 4개 영역 주석 이미지]

- **메뉴바**: 파일(File), 데이터(Data), 변환(Transform), 분석(Analyze), 그래프(Graphs), 설정(Settings) 메뉴를 제공합니다. 분석 기법별로 서브메뉴가 체계적으로 정리되어 있습니다.
- **데이터 뷰 (Data View)**: 스프레드시트 형태로 데이터를 표시합니다. 셀을 직접 클릭하여 값을 입력하거나 수정할 수 있으며, 상단의 Formula Bar에서 현재 셀의 값을 확인하고 편집합니다.
- **변수 뷰 (Variable View)**: 각 변수의 이름, 유형, 측정 척도, 값 라벨, 결측 규칙 등 메타데이터를 관리합니다. 분석 결과의 정확성을 높이려면 분석 전에 반드시 변수 속성을 정확히 설정하십시오.
- **결과 창 (Output View)**: 분석 결과가 구조화된 표와 차트로 표시됩니다. 왼쪽 트리 목록에서 분석 항목을 선택하면 오른쪽 상세 보기에 해당 결과가 나타납니다.

### 2.3 데이터 불러오기

상단 메뉴에서 **파일(File) > 열기(Open)**를 선택하거나 Ctrl+O를 누릅니다. 지원하는 파일 형식은 다음과 같습니다.

| 형식 | 확장자 | 비고 |
|------|--------|------|
| CSV / TSV | .csv, .txt, .tsv | UTF-8, CP949 자동 감지 |
| Excel | .xlsx | 시트 선택 가능 |
| SPSS 데이터 파일 | .sav | 값 라벨, 결측 설정 자동 임포트 |
| 클립보드 | — | 다른 프로그램에서 복사한 데이터 붙여넣기 |
| StatWorkbench 프로젝트 | .swb | 데이터, 변수 정의, 결과 일괄 저장 |

파일을 불러오면 데이터 뷰에 스프레드시트 형태로 데이터가 표시되고, 변수 뷰에 각 열의 기본 속성이 자동으로 설정됩니다. .sav 파일을 불러오는 경우 SPSS에서 정의한 값 라벨과 결측 규칙이 함께 적용됩니다.

[그림: 파일 열기 대화 상자]

### 2.4 수동 데이터 입력

StatWorkbench는 SPSS 스타일의 스프레드시트를 통해 데이터를 직접 입력할 수 있습니다. 파일이 없더라도 빈 데이터 뷰에서 바로 작업을 시작하십시오.

**Formula Bar 사용법**

화면 상단의 Formula Bar는 왼쪽의 **이름 상자**와 오른쪽의 **값 입력 바**로 구성됩니다. 이름 상자에는 현재 선택된 셀의 위치(예: R1C1)가 표시되고, 값 입력 바에서 셀 내용을 입력하거나 수정합니다. Enter 키로 입력을 확정합니다.

**결측값 입력**

결측값은 해당 셀에 마침표(".")를 입력합니다. 결측값이 입력된 셀은 회색 음영으로 표시되어 일반 값과 구분됩니다. 결측값은 분석 시 자동으로 제외되며, 사례 처리 요약(Case Processing Summary)에 결측 건수가 함께 보고됩니다.

**키보드 단축키**

| 단축키 | 기능 |
|--------|------|
| Enter | 입력 확정 후 아래 셀로 이동 |
| Tab | 입력 확정 후 오른쪽 셀로 이동 |
| F2 | 현재 셀 편집 모드 진입 |
| Delete | 현재 셀 값 삭제 |
| Ctrl+D | Fill Down (선택 범위 위 값 복사) |
| Ctrl+C / Ctrl+V | 복사 / 붙여넣기 |

## 3. 변수 관리

### 3.1 변수 뷰 탭 사용법

화면 하단의 **변수 뷰** 탭을 클릭하거나 Ctrl+2를 누르면 변수 관리 화면으로 전환됩니다. 각 행이 하나의 변수(열)를 나타내며, 열 머리글을 클릭하여 속성을 편집합니다.

[그림: 변수 뷰 전체 화면]

주요 속성은 다음과 같습니다.

- **이름(Name)**: 변수 식별자. 영문, 숫자, 밑줄 조합 권장 (한글도 지원)
- **유형(Type)**: 숫자(Numeric), 문자열(String) 중 선택
- **소수점(Decimals)**: 소수점 이하 자릿수 (데이터 뷰 표시에 반영)
- **레이블(Label)**: 결과 출력에 표시되는 설명적 변수명 (한글 권장)
- **값 라벨(Values)**: 코드값에 대응하는 라벨 (예: 1=남성, 2=여성)
- **결측(Missing)**: 시스템 결측 외 사용자 정의 결측값 지정

### 3.2 측정 척도 설정

변수의 측정 수준을 올바르게 설정하면 적절한 분석 기법이 자동으로 권장됩니다. 세 가지 척도 중 하나를 선택합니다.

- **척도(Scale)**: 등간·비율 척도. 연속형 수치 변수 (나이, 키, 점수 등)
- **명목(Nominal)**: 명목 척도. 순서 없는 범주 변수 (성별, 지역 등)
- **순서(Ordinal)**: 순서 척도. 순서 있는 범주 변수 (만족도, 학력 등)

데이터 뷰의 열 머리글에는 척도 유형에 따라 아이콘이 표시됩니다(▪ 척도, ● 명목, ◆ 순서).

### 3.3 값 라벨 설정

값 라벨을 설정하면 코드값(1, 2, 3) 대신 의미 있는 텍스트(남성, 여성, 기타)가 결과표에 출력됩니다. 변수 뷰의 **값(Values)** 열을 클릭하면 값 라벨 편집 대화 상자가 열립니다. 값과 라벨을 입력하고 **추가(Add)** 버튼을 눌러 목록에 등록합니다.

### 3.4 변수 계산 (Compute Variable)

**변환(Transform) > 변수 계산(Compute Variable)** 메뉴를 선택합니다. 대상 변수명과 수식을 입력하면 새로운 변수가 생성됩니다. 사칙연산, 수학 함수(SQRT, LN, ABS 등), 조건식을 조합하여 복잡한 파생 변수도 생성할 수 있습니다.

### 3.5 변수 재코딩 (Recode)

**변환(Transform) > 재코딩(Recode)** 메뉴에서 기존 변수의 값을 다른 값으로 변환합니다. 예를 들어 연령(20, 35, 50)을 연령대(1=청년, 2=중년, 3=장년)로 변환하는 데 활용합니다. 원본 변수를 유지하려면 **다른 변수로 재코딩(Into Different Variables)**을 선택하십시오.

### 3.6 시각적 구간화 (Visual Binning)

**변환(Transform) > 시각적 구간화(Visual Binning)** 메뉴를 선택하면 히스토그램을 보면서 연속형 변수를 범주형으로 변환할 수 있습니다. 구간 경계값을 직접 입력하거나 동일 간격 / 동일 분위수 자동 분할을 선택합니다.

## 4. 기술통계 분석

기술통계 분석은 데이터의 전반적인 분포와 특성을 파악하는 첫 번째 단계입니다. **분석(Analyze) > 기술통계량(Descriptive Statistics)** 메뉴에서 아래 분석을 수행합니다.

### 4.1 빈도분석 (Frequencies)

빈도분석은 범주형 변수의 각 값이 몇 번 나타나는지 확인하는 데 사용합니다. 설문 응답 분포, 지역별 사례 수 파악 등에 적합합니다.

**분석 수행 방법**: **분석 > 기술통계량 > 빈도분석** 선택 → 분석할 변수를 오른쪽 목록으로 이동 → **확인** 클릭

결과표에는 각 값의 빈도수(Count), 퍼센트(%), 유효 퍼센트, 누적 퍼센트가 출력됩니다. 유효 퍼센트는 결측값을 제외하고 계산되므로 실질적인 분포 해석에 활용합니다.

[그림: 빈도분석 대화 상자]

### 4.2 기술통계량 (Descriptives)

연속형 변수의 집중경향과 산포도를 요약합니다. 기본 출력 항목은 다음과 같습니다.

| 통계량 | 설명 |
|--------|------|
| 평균(Mean) | 산술 평균 |
| 표준편차(Std. Dev.) | 관측값의 평균 편차 |
| 최솟값 / 최댓값 | 범위 확인 |
| 왜도(Skewness) | 분포의 비대칭성 (0에 가까울수록 정규분포에 근접) |
| 첨도(Kurtosis) | 분포의 뾰족함 (0이 정규분포 수준) |

왜도 절댓값이 2 이상이거나 첨도 절댓값이 7 이상이면 정규성 가정을 재검토하십시오.

### 4.3 탐색 (Explore)

**분석 > 기술통계량 > 탐색** 메뉴는 기술통계량과 정규성 검정, 상자그림(Boxplot)을 한 번에 제공합니다. 분석 전 데이터 분포를 종합적으로 파악하는 데 유용합니다. 집단 변수를 지정하면 집단별 비교도 가능합니다.

### 4.4 교차분석 (Crosstabs)

두 범주형 변수 간의 관계를 분석합니다. **분석 > 기술통계량 > 교차분석** 메뉴에서 행 변수와 열 변수를 지정합니다.

- **카이제곱 검정**: 두 변수 간 독립성 검정. p < 0.05이면 변수 간 유의한 연관이 있음을 의미합니다. 기대빈도가 5 미만인 셀이 20%를 초과하면 피셔의 정확 검정(Fisher's Exact Test) 결과를 참조하십시오.
- **위험도 추정**: 2×2 표에서 교차비(Odds Ratio), 상대 위험도(Relative Risk)를 산출합니다.

## 5. 평균 비교

집단 간 평균 차이가 통계적으로 유의한지 검정합니다. **분석(Analyze) > 평균 비교(Compare Means)** 메뉴를 사용합니다.

### 5.1 단일표본 T 검정

표본 평균이 특정 기준값(검정값)과 유의미하게 다른지 검정합니다. 예를 들어 "이 지역 초등학생 평균 신장이 전국 평균(135cm)과 다른가?"를 검정할 때 사용합니다.

**분석 수행**: 검정 변수 선택 → 검정값(Test Value) 입력 → 확인. 결과에서 t값, 자유도, p값, 평균 차이, 95% 신뢰 구간이 출력됩니다.

### 5.2 독립표본 T 검정

독립된 두 집단의 평균을 비교합니다. 집단 변수와 비교할 연속형 변수를 지정하면 자동으로 레빈의 등분산 검정(Levene's Test)을 먼저 수행합니다.

- **레빈 검정 p ≥ 0.05**: 등분산 가정 충족 → 합동 분산 t 검정 결과 사용
- **레빈 검정 p < 0.05**: 등분산 가정 위반 → Welch 수정 t 검정 결과 사용

결과표에 코헨의 d(Cohen's d) 효과 크기가 자동 산출됩니다. |d| ≥ 0.8이면 큰 효과, 0.5~0.8이면 중간 효과, 0.2~0.5이면 작은 효과로 해석합니다.

### 5.3 대응표본 T 검정

동일 개체에서 측정 전후 또는 두 조건의 평균 차이를 비교합니다. 변수 쌍을 지정하면 차이값의 평균, t값, p값, 95% 신뢰 구간이 출력됩니다.

### 5.4 일원분산분석 (One-Way ANOVA)

세 집단 이상의 평균을 동시에 비교합니다. 집단 변수(요인)와 종속 변수를 지정합니다.

**사후 검정 (Post Hoc Tests)**: F 검정에서 집단 간 유의한 차이가 있을 때 어느 집단 쌍이 다른지 파악하기 위해 사후 검정을 수행합니다.

| 방법 | 적합 상황 |
|------|-----------|
| Tukey HSD | 등분산, 동일 표본 크기 |
| Bonferroni | 소수의 사전 계획 비교 |
| Scheffe | 보수적 검정, 불균등 표본 |

## 6. 상관 및 회귀 분석

### 6.1 상관분석

두 변수 간의 선형 관계 강도와 방향을 측정합니다. **분석 > 상관(Correlate) > 이변량(Bivariate)** 메뉴를 사용합니다.

- **피어슨 상관(Pearson)**: 연속형 변수, 정규분포 가정
- **스피어만 상관(Spearman)**: 순서 척도 또는 정규성 가정 위반 시
- **켄달 타우(Kendall's tau)**: 소표본, 동순위(Ties)가 많을 때

|r| ≥ 0.7이면 강한 상관, 0.4~0.7이면 중간 상관, < 0.4이면 약한 상관으로 해석합니다. 상관관계가 있다고 해서 인과관계가 성립하는 것은 아님에 주의하십시오.

### 6.2 선형 회귀

하나 이상의 예측 변수로 연속형 종속 변수를 예측합니다. **분석 > 회귀(Regression) > 선형(Linear)** 메뉴를 사용합니다.

결과표에 포함되는 주요 항목은 다음과 같습니다.

| 항목 | 해석 |
|------|------|
| R² | 모형 설명력 (0~1, 높을수록 좋음) |
| 비표준화 계수(B) | 예측 변수 1단위 증가 시 종속 변수 변화량 |
| 표준화 계수(Beta) | 변수 간 상대적 영향력 비교 |
| VIF | 다중공선성 지표 (10 초과 시 주의) |
| 유의확률(p) | 각 예측 변수의 통계적 유의성 |

### 6.3 로지스틱 회귀

종속 변수가 이진형(0/1) 또는 명목 범주형인 경우 사용합니다. **분석 > 회귀 > 로지스틱** 메뉴에서 이항(Binary) 또는 다항(Multinomial)을 선택합니다.

결과표에는 계수(B), 표준 오차, 교차비(Odds Ratio, Exp(B)), 95% 신뢰 구간, 호스머-레메쇼 적합도 검정, ROC AUC가 포함됩니다. Odds Ratio가 1보다 크면 해당 예측 변수가 결과 발생 확률을 높이는 방향으로 작용함을 의미합니다.

---

## 7. 비모수 검정

정규성 가정이 충족되지 않거나 표본 크기가 매우 작은 경우 비모수 검정을 사용합니다. **분석 > 비모수 검정(Nonparametric Tests)** 메뉴에서 선택합니다.

| 검정 | 대응하는 모수 검정 | 사용 상황 |
|------|-------------------|-----------|
| Mann-Whitney U | 독립표본 t 검정 | 두 독립 집단 비교 |
| Wilcoxon 부호순위 | 대응표본 t 검정 | 동일 개체 전후 비교 |
| Kruskal-Wallis | 일원분산분석 | 세 집단 이상 비교 |
| Friedman | 반복측정 ANOVA | 동일 개체 반복 측정 비교 |

비모수 검정은 순위(Rank) 기반으로 작동하므로 극단값(Outlier)의 영향을 덜 받습니다. 결과에서 p < 0.05이면 집단 간 분포에 유의한 차이가 있다고 해석합니다.

## 8. 고급 분석

### 8.1 정규성 검정

통계 검정 수행 전 데이터가 정규 분포를 따르는지 확인합니다. **분석 > 기술통계량 > 탐색** 또는 **분석 > 비모수 검정 > 정규성 검정** 메뉴를 이용합니다.

- **Shapiro-Wilk 검정**: 표본 크기 50 미만에 권장. p ≥ 0.05이면 정규성 충족
- **Kolmogorov-Smirnov 검정**: 대표본에 사용. 정규성 검정의 보조 지표로 활용

p < 0.05이면 정규성 가정이 기각되므로, 해당 변수에는 비모수 검정 또는 로버스트 검정을 사용하십시오.

### 8.2 요인분석 (EFA/PCA)

여러 변수 간의 공통 요인을 추출하여 설문 척도의 구성 타당도를 검증하거나 변수 수를 줄이는 데 사용합니다. **분석 > 차원 축소(Dimension Reduction) > 요인(Factor)** 메뉴를 선택합니다.

- **추출 방법**: 주성분 분석(PCA) 또는 최대 우도법(ML) 선택
- **회전 방법**: Varimax(직교 회전, 가장 일반적), Oblimin(사각 회전)
- **요인 수 결정**: 고유값(Eigenvalue) 1 이상인 요인 선택이 기본. 스크리 도표(Scree Plot)를 병행하여 결정

결과에는 KMO 표본 적절성 측도(0.6 이상 권장), 바틀렛 구형성 검정, 각 요인의 분산 설명량, 회전 요인 적재량 행렬이 출력됩니다.

[그림: 스크리 도표 예시]

### 8.3 군집분석

유사한 특성을 가진 개체를 자동으로 그룹화합니다. **분석 > 군집(Classify)** 메뉴에서 방법을 선택합니다.

**K-평균 군집 (K-Means Clustering)**

군집 수를 사전에 지정합니다. 최적 군집 수는 엘보우(Elbow) 도표와 실루엣(Silhouette) 계수를 참고하여 결정합니다. 결과에는 군집 중심값, 각 군집의 사례 수, ANOVA 표가 출력됩니다.

**계층적 군집 (Hierarchical Clustering)**

사전에 군집 수를 지정하지 않고 덴드로그램(Dendrogram)을 통해 구조를 파악합니다. 연결 방법(Ward, Complete, Average)을 선택합니다. Ward 방법은 집단 내 분산을 최소화하여 일반적으로 좋은 결과를 제공합니다.

### 8.4 생존분석

사건(Event)이 발생하기까지의 시간을 분석합니다. **분석 > 생존분석(Survival)** 메뉴를 사용합니다.

**Kaplan-Meier 생존 곡선**

시간 변수와 사건 변수를 지정하면 생존 함수 곡선이 출력됩니다. 집단 변수를 추가하면 Log-rank 검정으로 집단 간 생존 곡선 차이를 비교합니다. 곡선이 급격히 하강할수록 해당 시점에 사건이 많이 발생함을 의미합니다.

**Cox 비례위험 회귀**

여러 공변량이 생존에 미치는 영향을 동시에 분석합니다. 위험비(Hazard Ratio, HR)가 1보다 크면 해당 변수가 사건 발생 위험을 높이는 요인임을 나타냅니다.

[그림: Kaplan-Meier 생존 곡선 예시]

### 8.5 판별분석 (LDA)

여러 연속형 변수를 이용해 개체가 속한 집단을 분류합니다. **분석 > 군집 > 판별(Discriminant)** 메뉴를 사용합니다.

결과에는 윌크스 람다(Wilks' Lambda, 낮을수록 판별력 높음), 정준 판별 함수 계수, 분류 정확도(올바르게 분류된 비율)가 출력됩니다. 분류 정확도가 75% 이상이면 실용적 수준의 판별 모형으로 평가합니다.

## 9. 시각화

### 9.1 차트 빌더 사용법

**그래프(Graphs) > 차트 빌더(Chart Builder)** 메뉴를 선택합니다. 7종의 차트 유형을 지원합니다.

| 차트 유형 | 적합 상황 |
|-----------|-----------|
| 막대 그래프(Bar Chart) | 범주별 빈도 또는 평균 비교 |
| 히스토그램(Histogram) | 연속형 변수 분포 확인 |
| 상자 그림(Box Plot) | 중앙값, 사분위수, 이상값 시각화 |
| 산점도(Scatter Plot) | 두 연속형 변수 간 관계 |
| 선 그래프(Line Chart) | 시계열 또는 순서 있는 범주 변화 |
| 파이 차트(Pie Chart) | 범주별 구성비 |
| 생존 곡선(Survival Plot) | Kaplan-Meier 결과 시각화 |

X축 변수, Y축 변수, 집단 변수(색상)를 지정하면 실시간 미리보기가 제공됩니다. **삽입(Insert)** 버튼을 클릭하면 현재 결과 창에 차트가 추가됩니다.

### 9.2 차트 저장

결과 창에 삽입된 차트를 우클릭하면 **PNG로 저장** 옵션이 나타납니다. 300 DPI 해상도로 저장되므로 보고서 삽입에 바로 활용할 수 있습니다.

## 10. 결과 출력

### 10.1 결과 창 구조

결과 창은 두 영역으로 구성됩니다. 왼쪽 **트리 목록**에는 수행된 분석이 시계열 순서로 나열되며, 항목을 클릭하면 오른쪽 **상세 보기**에 해당 결과표와 차트가 표시됩니다.

각 분석 결과 블록에는 분석 명칭, 사례 처리 요약, 주요 결과표, 해석 가이드가 포함됩니다. 별표(*, **, ***)는 통계적 유의수준을 나타냅니다(* p < .05, ** p < .01, *** p < .001).

### 10.2 HTML 내보내기

**파일(File) > 결과 내보내기(Export Output) > HTML** 메뉴를 선택하면 현재 결과 창의 모든 표와 차트를 하나의 HTML 파일로 저장합니다. 저장된 HTML 파일은 웹 브라우저에서 바로 열 수 있으며, 보고서 작성 시 복사·붙여넣기가 용이합니다.

### 10.3 구문(Syntax) 로그 확인

모든 분석 수행 시 해당 분석의 구문이 자동으로 기록됩니다. **보기(View) > 구문 로그(Syntax Log)** 메뉴에서 확인할 수 있습니다. 구문 로그를 복사하여 다시 실행하면 동일한 분석 결과를 재현할 수 있습니다.
