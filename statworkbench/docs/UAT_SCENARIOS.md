## UAT-001: 첫 실행 및 기본 데이터 입력

### 목적
앱이 정상적으로 실행되고, 빈 데이터셋에서 직접 데이터를 입력할 수 있는지 확인한다.

### 사전 조건
- Python 3.14 + PySide6 환경 구축 완료
- `python -m statworkbench` 또는 실행 파일로 앱 시작 가능

### 테스트 절차

| 단계 | 동작 | 기대 결과 |
|------|------|----------|
| 1 | 앱을 실행한다 | 창 타이틀 "StatWorkbench - Untitled" 표시, 좌측 Data View 활성 |
| 2 | Data View의 첫 번째 셀을 더블클릭한다 | 셀 편집 모드 진입 |
| 3 | "25" 입력 후 Enter | 값 저장, 다음 행으로 이동 |
| 4 | Tab 키로 우측 셀 이동 후 "30" 입력 | 값 저장, 다음 열로 이동 |
| 5 | 화살표 키로 셀 이동 | 상하좌우 이동 정상 |
| 6 | "+ 변수 추가" 버튼 클릭 | 새 열 추가, 이름 "VAR00001" |
| 7 | "+ 행 추가" 버튼 클릭 | 새 행 추가, 행 번호 증가 |
| 8 | 헤더(변수명) 더블클릭 후 "age"로 변경 | 변수명 변경, Variable View에 반영 |
| 9 | Variable View 탭 클릭 | 11개 속성 컬럼 표시, "age" 변수 목록에 표시 |
| 10 | Measure 셀 더블클릭 후 "SCALE" 선택 | 측정 척도 변경, 셀 배경색 연한 초록으로 변경 |

### 완료 기준
- 모든 단계에서 오류 대화상자 미발생
- Data View ↔ Variable View 동기화 정상

## UAT-002: CSV 데이터 가져오기 및 확인

### 목적
외부 CSV 파일을 가져와 데이터가 정상적으로 로드되는지 확인한다.

### 테스트 절차

| 단계 | 동작 | 기대 결과 |
|------|------|----------|
| 1 | 파일 → 가져오기 → CSV 파일 선택 | 파일 선택 대화상자 열림 |

| 4 | Variable View 탭 클릭 | CSV 컬럼명으로 변수 목록 표시 |
| 5 | 정보 바 확인 | "{N}행 × {M}변수" 형식 표시 |

## UAT-006: 독립표본 T 검정

### 목적
두 그룹 간 평균 차이를 독립표본 T 검정으로 분석한다.

### 사전 조건
- 그룹 변수(2개 범주)와 종속 변수(연속형) 존재

### 테스트 절차

| 단계 | 동작 | 기대 결과 |
|------|------|----------|
| 1 | 분석 → 평균 비교 → 독립표본 T 검정 선택 | Independent T-Test 대화상자 열림 |
| 2 | 종속 변수(예: score) 선택 | Test Variable에 추가 |
| 3 | 그룹 변수(예: gender, 2범주) 선택 | Grouping Variable에 추가 |
| 4 | 실행 | 결과 출력 |
| 5 | Group Statistics 확인 | 그룹별 N, Mean, SD, SE |
| 6 | Levene's Test 확인 | F, p-value 출력 |
| 7 | Independent Samples t-Test 확인 | Equal variances assumed / not assumed 두 행 |
| 8 | t, df, p-value, Mean Difference, 95% CI 확인 | 모든 값 표시 |
| 9 | Cohen's d 값 확인 | 효과크기 지표 표시 |
| 10 | 도구모음 "📉 T 검정" 버튼 클릭 | 동일한 대화상자 열림 |

### 완료 기준
- Levene p < 0.05 시 Welch t-test 해석
- p-value와 95% CI의 일관성 확인

## UAT-007: 대응표본 T 검정

### 목적
동일 대상의 전/후 측정 데이터를 대응표본 T 검정으로 분석한다.

### 사전 조건
- 전/후 측정 변수 2개 존재 (예: pre_test, post_test)

### 테스트 절차

| 단계 | 동작 | 기대 결과 |
|------|------|----------|
| 1 | 분석 → 평균 비교 → 대응표본 T 검정 선택 | Paired T-Test 대화상자 열림 |
| 2 | 변수 1 (pre_test) 선택 | Pair 1 Variable 1에 추가 |
| 3 | 변수 2 (post_test) 선택 | Pair 1 Variable 2에 추가 |
| 4 | 실행 | 결과 출력 |
| 5 | Paired Samples Statistics 확인 | 각 변수 N, Mean, SD, SE |
| 6 | Paired Samples t-Test 확인 | Mean Difference, SD Difference, SE Difference |
| 7 | t, df, p-value, 95% CI 확인 | 모든 값 표시 |
| 8 | Cohen's dz 확인 | dz = Mean Diff / SD Diff |

### 완료 기준
- Mean Difference = Variable1 Mean - Variable2 Mean
- p < 0.05 시 통계적으로 유의미한 차이

## UAT-008: 일원분산분석 (ANOVA)

### 목적
3개 이상 그룹 간 평균 차이를 ANOVA로 분석한다.

### 사전 조건
- 그룹 변수(3개 이상 범주)와 종속 변수(연속형) 존재

### 테스트 절차

| 단계 | 동작 | 기대 결과 |
|------|------|----------|
| 1 | 분석 → 평균 비교 → 일원분산분석 선택 | ANOVA 대화상자 열림 |
| 2 | 종속 변수(예: score) 선택 | Dependent Variable에 추가 |
| 3 | 요인 변수(예: group, 3범주 이상) 선택 | Factor에 추가 |
| 4 | 사후검정 옵션: Tukey 선택 | Post Hoc 설정 |
| 5 | 실행 | 결과 출력 |
| 6 | Descriptives 확인 | 그룹별 N, Mean, SD, SE |
| 7 | Levene's Test 확인 | 등분산성 가정 검정 |
| 8 | ANOVA 테이블 확인 | Between Groups / Within Groups SS, df, MS, F, p |
| 9 | 효과크기 확인 | eta-squared, omega-squared |
| 10 | Tukey HSD 확인 | 그룹 쌍별 비교, p-value |

### 완료 기준
- F 값과 p-value가 statsmodels 결과와 일치
- Tukey 결과에서 그룹 쌍 조합이 모두 포함

| 3 | 독립 변수(예: age, income) 선택 | Independents에 추가 |

두 범주형 변수의 연관성을 교차표와 카이제곱 검정으로 분석한다.

### 사전 조건
- 행/열 변수 모두 범주형

### 테스트 절차

| 단계 | 동작 | 기대 결과 |
|------|------|----------|
| 1 | 분석 → 기술통계 → 교차분석 선택 | Crosstabs 대화상자 열림 |
| 2 | 행 변수(예: treatment) 선택 | Row에 추가 |
| 3 | 열 변수(예: response) 선택 | Column에 추가 |

# 대용량 테스트 데이터 생성 (UAT-017용)
import pandas as pd
import numpy as np

np.random.seed(42)
n = 100_000

df = pd.DataFrame({
    "id": range(1, n + 1),
    "group": np.random.choice(["A", "B", "C", "D"], n),
    "gender": np.random.choice(["M", "F"], n),
    "age": np.random.randint(18, 80, n),
    "income": np.random.normal(50000, 15000, n).round(2),
    "score1": np.random.normal(75, 10, n).round(2),
    "score2": np.random.normal(80, 12, n).round(2),
    "score3": np.random.normal(70, 15, n).round(2),
    "treatment": np.random.choice(["Drug", "Placebo"], n),
    "response": np.random.choice(["Yes", "No"], n),
})

# 추가 연속형 변수 40개
for i in range(1, 41):
    df[f"var_{i:02d}"] = np.random.normal(50, 20, n).round(2)

df.to_csv("large_test_data.csv", index=False, encoding="utf-8-sig")
print(f"생성 완료: {len(df)}행 x {len(df.columns)}열")
