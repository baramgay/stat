🐛 주요 버그 수정 이력

spss_writer.py
측정 척도 저장 오류 — str(measure) → measure.value.upper(). 모든 변수가 "nominal"로 저장되던 치명적 버그 수정.
spss_reader.py
meta.variable_measure 미사용 → 직접 읽도록 수정. float64이지만 정수 값만 있는 경우 INTEGER로 판별.
exporters.py
DataFrame truthiness 버그 — or 연산 → is not None 체크. 빈 DataFrame이 falsy로 평가되어 다음 테이블로 넘어가던 문제.
import_wizard.py
pandas import 누락 — step_confirm에서 pd.isna() 호출 시 NameError 발생. import 추가로 수정.
validation.py
ORDINAL + FLOAT 비호환 — SPSS 29 기준으로 FLOAT 허용 추가. 실수형 순서형 변수 분석 불가 오류.
spss_grid_model.py
storage_type 승격 실패 — first_value만 보던 것을 전체 값 스캔으로 변경. 숫자/문자 혼합 컬럼 처리 개선.
registry.py
one_sample_t_test 오표시 — ttests.py에 구현되어 있으나 implemented: False로 표시. True로 수정.
