# 주간보고 — StatWorkbench 통계패키지 개발

## 1. 사업 개요

| 항목 | 내용 |
|------|------|
| **사업명** | StatWorkbench 통계분석 패키지 개발 |
| **사업내용** | 공공데이터 기반 통계분석 도구 개발 |
| **사업목적** | 경남빅데이터허브플랫폼 탑재를 통한 공무원·도민 통계분석 편의 제공 |
| **추진기간** | 2025.05.18 ~ 2025.06.30 (약 6주) |
| **완료예정** | 2025.06.30 |

## 2. 추진경과

### 기획 단계 (5.18 ~ 5.22)

- **5.18 (월)** — 프로젝트 기획 착수, SPSS 인터페이스 벤치마킹, 핵심 기능 정의
- **5.19 (화)** — 기술스택 선정(Python 3.14 + PySide6), 프로젝트 구조 설계, 개발환경 구축
- **5.20 (수)** — UI/UX 설계(데이터보기/변수보기/구문편집기 3영역), 테마 시스템 설계
- **5.21 (목)** — 데이터 모델 설계(SPSS 격자방식), 분석 엔진 아키텍처 설계
- **5.22 (금)** — 기획 완료, 세부 개발계획 수립, 테스트 전략 확정

### 제작 단계 (5.25 ~ 6.30)

- **5.25 (월)** — 코어 모듈 개발(데이터셋, 변수, 프로젝트), 기본 UI 구현
- **5.26 (화)** — 데이터 뷰 구현(1000x100 격자, 셀 편집, 키보드 네비게이션)
- **5.27 (수)** — 분석 엔진 개발(기술통계, T검정, 회귀분석, 교차분석)
- **5.28 (목)** — 다이얼로그 시스템 구현(빈도, 기술통계, T검정, 회귀, 교차분석)
- **5.29 (금)** — 파일 I/O 구현(CSV, Excel, SPSS .sav 가져오기/낳볼기)
- **6.01 (월)** — 고급 분석 기능(ANOVA, 상관분석, 비모수검정)
- **6.02 (화)** — 데이터 변환 기능(재코딩, 구간화, 순위계산, 변수계산)
- **6.03 (수)** — 시각화 기능 통합(matplotlib, plotly 기반 차트 생성)
- **6.04 (목)** — R/Python 연동 스크립트 실행 기능
- **6.05 (금)** — 보고서 생성 엔진(HTML 보고서 자동 생성)
- **6.08 (월)** — 데이터 품질 진단 기능(결측치, 이상치, 중복 검사)
- **6.09 (화)** — 고급 데이터 조작(케이스선택, 가중치, 파일병합, 피벗테이블)
- **6.10 (수)** — UI/UX 대폭 개선(하단탭, 독립 결과창, 설정저장)
- **6.11 (목)** — 성능 최적화, 메모리 사용량 개선, import 시간 단축
- **6.12 (금)** — 통합 테스트, 버그 수정, QA 검증
- **6.15 (월)** — 사용자 매뉴얼 초안 작성, 납비 문서 준비
- **6.16 (화)** — 최종 테스트 및 안정화
- **6.17 (수)** — 경남빅데이터허브플랫폼 탑재 준비
- **6.18 (목)** — 탑재 테스트, 호환성 검증
- **6.19 (금)** — 최종 납비 및 사업 완료
