# NuriStat QA 체크리스트

> 버전: 1.0.0  
> 작성일: 2026-05-18  
> 대상: PySide6 기반 데스크톱 통계 패키지 (550개 pytest 통과 기준)

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 앱 이름 | NuriStat |
| 기술 스택 | Python 3.14 + PySide6 + pandas + scipy + statsmodels + matplotlib |
| UI 스타일 | SPSS 스타일 메뉴/뷰 구조 |
| 테스트 수 | 550개 (pytest) |
| 주요 기능 | Data View, Variable View, 분석, Chart Builder, Syntax Editor |

## 10. 체크리스트 사용 방법

1. **테스트 실행 전**: 테스트 환경(OS, Python 버전, 의존성) 기록
2. **P0 항목 우선**: 모든 P0 항목 PASS 확인 후 P1/P2 진행
3. **결과 기록**: 각 항목별 PASS/FAIL/NA 기록, 이슈 시 재현 절차와 스크린샷 첨부
4. **회귀 테스트**: 코드 변경 시 P0 전체 + 변경 영역 P1 재실행
5. **자동화 연계**: pytest 550개 단위 테스트는 CI에서 자동 실행, 본 체크리스트는 수동 QA용
