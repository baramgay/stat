## 1. 소개

### 1.1 NuriStat란?

NuriStat는 코드를 몰라도 통계 분석을 할 수 있도록 만들어진 **메뉴 기반 데스크톱 통계 프로그램**입니다. SPSS처럼 메뉴와 대화 상자로 분석 옵션을 선택하면, 프로그램이 알아서 계산하고 결과표를 출력합니다.

연구자, 공공기관 담당자, 학생, 의료 전문가 등 **데이터를 다루지만 코딩은 어려운 분**들을 위해 설계되었습니다.

### 1.2 주요 특징

- **메뉴 기반**: 마우스와 키보드만으로 모든 분석 수행
- **한글 완벽 지원**: 변수명, 값 라벨, 결과 출력 전반에서 한글 표시
- **오류 방지 설계**: 잘못된 변수 유형 선택 시 경고 메시지 자동 표시
- **재현 가능**: 구문 로그가 자동 생성되어 동일 분석 반복 실행 가능
- **Light / Dark 테마**: Ctrl+Shift+D로 전환
- **37종 분석**: 기술통계부터 생존분석, 기계학습까지 지원

### 1.3 시스템 요구사항

| 항목 | 최소 사양 | 권장 사양 |
|------|-----------|-----------|
| 운영체제 | Windows 10 (64비트) | Windows 11 |
| RAM | 4 GB | 8 GB 이상 |
| 저장 공간 | 500 MB | 1 GB 이상 |
| 화면 해상도 | 1280×768 | 1920×1080 이상 |

## 2. 시작하기

### 2.1 설치 방법

**방법 1 — pip 설치 (개발자용)**

```bash
pip install -e ".[dev]"
python -m nuristat
```

**방법 2 — 배치 파일 실행 (일반 사용자 권장)**

프로젝트 루트 폴더의 `run.bat`를 더블 클릭합니다. 가상환경을 자동으로 설정하고 프로그램을 시작합니다.

**방법 3 — 독립 실행 파일 (.exe)**

`dist\NuriStat\NuriStat.exe`를 직접 실행합니다. Python 설치 없이 사용 가능합니다.

### 2.2 화면 구성

NuriStat의 메인 화면은 네 영역으로 구성됩니다.

```
┌─────────────────────────────────────────────┐
│  메뉴바  (File / Data / Analyze / ...)       │
├─────────────────────────┬───────────────────┤
│                         │                   │
│  데이터 뷰 (Data View)  │  결과 창           │
│  변수 뷰 (Variable View)│  (Output View)    │
│                         │                   │
└─────────────────────────┴───────────────────┘
```

- **메뉴바**: 파일, 데이터, 변환, 분석, 그래프, 설정 메뉴 제공
- **데이터 뷰**: 스프레드시트 형태로 데이터 표시 및 입력
- **변수 뷰**: 각 변수의 이름, 유형, 척도, 라벨 등 메타데이터 관리
- **결과 창**: 분석 결과를 구조화된 표와 차트로 표시

### 2.3 데이터 불러오기

**파일(File) > 열기(Open)** 또는 `Ctrl+O`를 누릅니다.

| 형식 | 확장자 | 비고 |
|------|--------|------|
| CSV / TSV | .csv, .txt, .tsv | UTF-8, CP949 자동 감지 |
| Excel | .xlsx | 시트 선택 가능 |
| SPSS 데이터 | .sav | 값 라벨·결측 설정 자동 임포트 |
| 클립보드 | — | 다른 프로그램에서 복사한 데이터 붙여넣기 |
| 프로젝트 | .swb | 데이터·변수 정의·설정 일괄 저장 |

파일을 불러오면 데이터 뷰에 스프레드시트, 변수 뷰에 각 열의 기본 속성이 자동 설정됩니다.

### 2.4 수동 데이터 입력

파일 없이도 빈 데이터 뷰에서 직접 입력할 수 있습니다.

**Formula Bar**: 화면 상단의 입력 바에서 현재 셀의 값을 확인하고 수정합니다. Enter 키로 확정합니다.

**결측값 입력**: 빈 셀에 마침표(".")를 입력하면 결측값으로 처리됩니다. 회색 음영으로 표시되며 분석 시 자동 제외됩니다.

**키보드 단축키**

| 단축키 | 기능 |
|--------|------|
| Enter | 입력 확정 후 아래 셀로 이동 |
| Tab | 입력 확정 후 오른쪽 셀로 이동 |
| F2 | 현재 셀 편집 모드 |
| Delete | 현재 셀 값 삭제 |
| Ctrl+D | Fill Down (선택 범위 위 값 복사) |
| Ctrl+C / Ctrl+V | 복사 / 붙여넣기 |

## 3. 변수 관리

### 3.1 변수 뷰 탭 사용법

화면 하단의 **변수 뷰** 탭을 클릭하거나 `Ctrl+2`를 누릅니다. 각 행이 하나의 변수(열)를 나타냅니다.

주요 속성:

- **이름(Name)**: 변수 식별자. 영문·숫자·밑줄 조합 권장 (한글도 지원)
- **유형(Type)**: 숫자(Numeric) 또는 문자열(String)
- **소수점(Decimals)**: 소수점 이하 자릿수 (데이터 뷰 표시에 반영)
- **레이블(Label)**: 결과 출력에 표시되는 설명적 변수명 (한글 권장)
- **값 라벨(Values)**: 코드값에 대응하는 라벨 (예: 1=남성, 2=여성)
- **결측(Missing)**: 시스템 결측 외 사용자 정의 결측값 지정

### 3.2 측정 척도 설정

> **왜 척도를 설정해야 하나요?**
> 성별(1=남, 2=여)은 숫자처럼 보이지만 평균을 구하면 의미 없는 값이 나옵니다.
> 척도 설정은 "이 변수를 어떤 방식으로 다룰지" 프로그램에 알려주는 작업입니다.

| 척도 | 설명 | 예시 |
|------|------|------|
| **척도(Scale)** | 연속형 수치. 더하기·빼기·평균이 의미 있음 | 나이, 키, 시험 점수 |
| **명목(Nominal)** | 순서 없는 범주. 분류만 가능 | 성별, 지역, 혈액형 |
| **순서(Ordinal)** | 순서 있는 범주. 크고 작음은 비교 가능하나 차이가 균등하지 않음 | 만족도(매우불만~매우만족), 학력 |

> **중요**: 척도 설정이 잘못되면 분석 메뉴에서 변수가 표시되지 않거나 오류가 발생합니다. 분석 전 반드시 확인하세요.

### 3.3 값 라벨 설정

값 라벨을 설정하면 결과표에 코드(1, 2, 3) 대신 의미 있는 텍스트(남성, 여성, 기타)가 출력됩니다.

**설정 방법**: 변수 뷰의 **값(Values)** 열 클릭 → 값과 라벨 입력 → **추가(Add)** → **확인**

**예시**: 성별 변수에 `1 = "남성"`, `2 = "여성"` 설정

### 3.4 레이블(Label) 설정의 중요성

변수명은 짧고 기술적(예: `age_2024`)이지만, 레이블은 결과표에 표시될 설명입니다(예: `2024년 기준 나이`).

결과 창과 차트에서 변수명 대신 레이블이 표시되므로, 보고서 품질을 높이려면 모든 변수에 한글 레이블을 설정하는 것을 권장합니다.

### 3.5 변수 계산 (Compute Variable)

**변환(Transform) > 변수 계산(Compute Variable)** 메뉴에서 새로운 파생 변수를 생성합니다.

- **예시 1**: `BMI = 체중(kg) / 키(m)²`
- **예시 2**: `총점 = 문항1 + 문항2 + 문항3`
- **예시 3**: `로그변환 = LN(소득)` (심하게 치우친 분포 보정)

### 3.6 변수 재코딩 (Recode)

**변환(Transform) > 재코딩(Recode)** 메뉴에서 기존 값을 다른 값으로 변환합니다.

**예시**: 연령(20, 35, 50)을 연령대(1=청년, 2=중년, 3=장년)로 변환

> **팁**: 원본 변수를 유지하려면 **다른 변수로 재코딩(Into Different Variables)**을 선택하세요.

### 3.7 시각적 구간화 (Visual Binning)

**변환(Transform) > 시각적 구간화(Visual Binning)**에서 연속형 변수를 범주형으로 변환합니다. 히스토그램을 보면서 구간 경계값을 지정하거나, 동일 간격·동일 분위수 자동 분할을 선택합니다.

## 4. p-값과 통계적 유의성 이해하기

> 이 섹션은 통계를 처음 접하는 분들을 위해 핵심 개념을 쉽게 설명합니다.

### 4.1 p-값이란?

**p-값(p-value)** 은 "우연히 이런 결과가 나올 확률"입니다.

**비유**: 동전을 10번 던져서 8번 앞면이 나왔다면, 이것이 단순한 운일까요, 아니면 이 동전이 앞면이 나오기 쉬운 동전일까요?
- p-값이 크다 (예: 0.3) → "이 정도는 우연에서도 흔히 발생한다" → 특별하지 않다
- p-값이 작다 (예: 0.02) → "우연히 이런 결과가 나올 확률이 2%밖에 안 된다" → 뭔가 진짜 차이가 있을 것 같다

### 4.2 유의 수준(α)

통계에서는 보통 **p < 0.05** (5%)를 기준으로 "통계적으로 유의하다"고 판단합니다.

| p-값 | 보고 방법 | 의미 |
|------|-----------|------|
| p < 0.001 | p < .001 또는 *** | 매우 유의함 |
| 0.001 ≤ p < 0.01 | p < .01 또는 ** | 유의함 |
| 0.01 ≤ p < 0.05 | p < .05 또는 * | 유의함 |
| p ≥ 0.05 | p = .xxx 또는 ns | 유의하지 않음 |

> **주의사항**
> - p < 0.05라고 해서 "효과가 크다"는 뜻은 아닙니다. 표본이 매우 크면 작은 차이도 유의하게 나옵니다.
> - p ≥ 0.05라고 해서 "두 집단이 완전히 같다"는 뜻도 아닙니다.
> - 항상 **효과 크기(Effect Size)**와 **신뢰 구간**을 함께 해석하세요.

### 4.3 신뢰 구간 (Confidence Interval, CI)

**95% 신뢰 구간**이란 "이 범위 안에 실제 모집단 값이 있을 확률이 95%"라는 뜻입니다.

**예시**: 두 집단의 평균 차이가 5.2점이고, 95% CI = [2.1, 8.3]이라면
- "실제 차이는 2.1점~8.3점 사이일 것으로 추정된다"
- CI가 0을 포함하지 않으면 → 통계적으로 유의한 차이가 있음

### 4.4 효과 크기 (Effect Size)

효과 크기는 "얼마나 의미 있는 차이인가"를 측정합니다. p-값과 함께 반드시 보고해야 합니다.

| 지표 | 사용 분석 | 기준 |
|------|-----------|------|
| Cohen's d | t 검정 | 0.2=소, 0.5=중, 0.8=대 |
| η² (Eta-squared) | ANOVA | 0.01=소, 0.06=중, 0.14=대 |
| r | 상관분석 | 0.1=소, 0.3=중, 0.5=대 |
| R² | 회귀분석 | 모형 설명력 (0~1) |

## 5. 기술통계 분석

기술통계는 데이터의 기본 특성을 파악하는 첫 번째 단계입니다. **분석(Analyze) > 기술통계량(Descriptive Statistics)** 메뉴를 사용합니다.

### 5.1 빈도분석 (Frequencies)

#### 언제 쓰나요?
범주형 변수의 분포를 파악할 때 사용합니다.
- "설문 응답자 중 남성이 몇 명, 여성이 몇 명인가?"
- "지역별 응답 건수는?"

#### 분석 수행 방법

1. **분석 > 기술통계량 > 빈도분석** 선택
2. 분석할 변수를 오른쪽 목록으로 이동
3. **확인** 클릭

#### 결과 읽는 방법

| 열 | 설명 |
|----|------|
| 빈도(Count) | 해당 값이 나타난 횟수 |
| 퍼센트(%) | 결측 포함 전체 대비 비율 |
| 유효 퍼센트 | **결측 제외** 후 비율 (주로 이 값 사용) |
| 누적 퍼센트 | 해당 값까지의 누적 비율 |

> **팁**: 보고서에는 보통 **유효 퍼센트**를 사용합니다. 결측값이 많다면 결측 비율도 함께 보고하세요.

#### 주의사항
- 연속형 변수(나이, 점수)에 빈도분석을 하면 값마다 별도 행이 생겨 표가 매우 길어집니다. 연속형 변수는 기술통계량을 사용하세요.

---

### 5.2 기술통계량 (Descriptives)

#### 언제 쓰나요?
연속형 변수의 전반적인 분포를 요약할 때 사용합니다.
- "응답자의 평균 나이는? 가장 어린/많은 사람은?"
- "시험 점수의 평균과 표준편차는?"

#### 결과 읽는 방법

| 통계량 | 설명 | 해석 팁 |
|--------|------|---------|
| **N** | 유효 사례 수 | 결측 제외 |
| **평균(Mean)** | 모든 값의 합 ÷ 개수 | 극단값에 민감 |
| **표준편차(SD)** | 평균으로부터의 평균 거리 | 클수록 분포가 퍼져 있음 |
| **최솟값/최댓값** | 데이터 범위 확인 | 이상값 탐지에 유용 |
| **왜도(Skewness)** | 분포의 비대칭성 | 0이면 대칭, +이면 오른쪽 꼬리 |
| **첨도(Kurtosis)** | 분포의 뾰족한 정도 | 0이면 정규분포 수준 |

> **정규성 판단 기준**: 왜도 절댓값 ≥ 2 또는 첨도 절댓값 ≥ 7이면 분포가 심하게 치우쳐 있으므로, 평균 대신 중앙값을 보고하거나 비모수 검정을 고려하세요.

---

### 5.3 탐색 (Explore)

#### 언제 쓰나요?
기술통계량 + 정규성 검정 + 상자그림을 한 번에 확인하고 싶을 때.
분석을 시작하기 전 데이터의 품질과 분포를 종합적으로 점검하는 데 유용합니다.

집단 변수를 지정하면 **집단별 비교**도 가능합니다.

---

### 5.4 교차분석 (Crosstabs)

#### 언제 쓰나요?
두 범주형 변수 간에 관련이 있는지 파악할 때 사용합니다.
- "성별에 따라 선호 제품이 다른가?"
- "지역별로 찬반 의견이 다른가?"

#### 분석 수행 방법

1. **분석 > 기술통계량 > 교차분석** 선택
2. 행 변수(Row)와 열 변수(Column) 지정
3. **통계(Statistics)**에서 카이제곱 체크
4. **셀(Cell)**에서 행 퍼센트 또는 열 퍼센트 선택 → **확인**

#### 결과 읽는 방법

**카이제곱 검정 (Chi-Square Test)**
- p < 0.05 → 두 변수 간 유의한 연관이 있음
- p ≥ 0.05 → 두 변수 간 독립적 (연관 없음)

> **중요 가정**: 기대빈도가 5 미만인 셀이 20%를 초과하면 카이제곱 결과가 신뢰할 수 없습니다. 이 경우 결과표 하단의 **피셔의 정확 검정(Fisher's Exact Test)** 결과를 사용하세요.

**교차비(Odds Ratio)**: 2×2 표에서 사용. 한 집단이 다른 집단보다 특정 결과가 발생할 확률이 몇 배인지를 나타냅니다.
- OR > 1 → 노출군에서 결과 발생 확률이 더 높음
- OR = 1 → 차이 없음
- OR < 1 → 노출군에서 결과 발생 확률이 더 낮음

---

## 6. 평균 비교

집단 간 평균 차이가 통계적으로 의미 있는지 검정합니다. **분석(Analyze) > 평균 비교(Compare Means)** 메뉴를 사용합니다.

### 6.1 어떤 검정을 선택해야 하나요?

```
집단이 몇 개?
├─ 1개 (기준값과 비교) → 단일표본 t 검정
├─ 2개
│   ├─ 독립된 두 집단 → 독립표본 t 검정
│   └─ 동일 개체(전후 비교) → 대응표본 t 검정
└─ 3개 이상 → 일원분산분석 (ANOVA)
```

---

### 6.2 단일표본 t 검정 (One-Sample t-Test)

#### 언제 쓰나요?
우리 집단의 평균이 특정 기준값과 차이가 있는지 검정합니다.
- "이 지역 초등학생의 평균 신장이 전국 평균(135cm)과 다른가?"
- "우리 제품의 평균 처리 시간이 목표값(30초)을 초과하는가?"

#### 분석 수행 방법

1. **분석 > 평균 비교 > 단일표본 t 검정** 선택
2. 검정 변수 선택
3. **검정값(Test Value)** 입력 (비교할 기준값)
4. **확인**

#### 결과 읽는 방법

| 항목 | 해석 |
|------|------|
| t 통계량 | 양수이면 표본 평균 > 기준값, 음수이면 < 기준값 |
| 자유도(df) | 표본 크기 - 1 |
| p-값 | 우연에 의한 확률 |
| 평균 차이 | 표본 평균 - 기준값 |
| 95% CI | 실제 차이의 신뢰 구간 |

---

### 6.3 독립표본 t 검정 (Independent Samples t-Test)

#### 언제 쓰나요?
**서로 다른 두 집단**의 평균을 비교합니다.
- "남성과 여성의 평균 급여가 다른가?"
- "실험군과 대조군의 혈압 평균이 다른가?"

#### 분석 수행 방법

1. **분석 > 평균 비교 > 독립표본 t 검정** 선택
2. 검정 변수(연속형) 선택
3. 집단 변수(명목형) 선택 → **집단 정의** 클릭 → 두 집단 값 입력
4. **확인**

#### 결과 읽는 방법

**Step 1: 레빈의 등분산 검정(Levene's Test) 확인**
- Levene p ≥ 0.05 → 등분산 가정 충족 → **등분산 가정** 행의 t 검정 결과 사용
- Levene p < 0.05 → 등분산 가정 위반 → **등분산 미가정(Welch)** 행의 결과 사용

**Step 2: t 검정 결과 해석**
- p < 0.05 → 두 집단의 평균이 유의하게 다름
- p ≥ 0.05 → 유의한 차이 없음

**Step 3: 효과 크기 확인 (Cohen's d)**
- |d| ≥ 0.8 → 큰 효과
- 0.5 ≤ |d| < 0.8 → 중간 효과
- 0.2 ≤ |d| < 0.5 → 작은 효과

> **흔한 실수**: 레빈 검정 결과를 무시하고 항상 "등분산 가정" 행만 보는 경우가 있습니다. 반드시 레빈 검정 p-값을 먼저 확인하세요.

---

### 6.4 대응표본 t 검정 (Paired Samples t-Test)

#### 언제 쓰나요?
**동일한 개체**에서 두 번 측정한 값을 비교합니다.
- "교육 전후 지식 점수가 달라졌는가?"
- "왼손과 오른손 악력의 차이가 있는가?"
- "같은 환자의 두 가지 치료법 효과 비교"

#### 분석 수행 방법

1. **분석 > 평균 비교 > 대응표본 t 검정** 선택
2. 쌍을 이루는 두 변수를 선택 (예: 사전점수, 사후점수)
3. **확인**

#### 결과 읽는 방법

| 항목 | 해석 |
|------|------|
| 쌍의 평균 차이 | 첫 번째 변수 - 두 번째 변수의 평균 |
| t 통계량 | 양수이면 전자 > 후자 |
| p-값 | p < 0.05이면 유의한 차이 있음 |
| 95% CI | CI가 0을 포함하지 않으면 유의 |

---

### 6.5 일원분산분석 (One-Way ANOVA)

#### 언제 쓰나요?
**세 집단 이상**의 평균을 동시에 비교합니다.
- "A, B, C 세 지역의 평균 소득이 다른가?"
- "복용량(저/중/고) 수준별 치료 효과가 다른가?"

> **왜 t 검정을 여러 번 하지 않나요?**
> 검정을 여러 번 반복할수록 우연히 유의한 결과가 나올 확률이 증가합니다(1종 오류 누적). ANOVA는 모든 집단을 한 번에 비교하여 이 문제를 방지합니다.

#### 분석 수행 방법

1. **분석 > 평균 비교 > 일원분산분석** 선택
2. 종속 변수(연속형) 선택
3. 요인 변수(집단 구분, 명목/순서형) 선택
4. **사후 검정(Post Hoc)** 선택 → Tukey 체크
5. **확인**

#### 결과 읽는 방법

**ANOVA 표**

| 소스 | SS | df | MS | F | p-값 |
|------|----|----|----|----|------|
| 집단 간 | ... | k-1 | SS/df | MS집단간/MS집단내 | 유의성 |
| 잔차 | ... | N-k | ... | — | — |

- F 통계량 → 클수록 집단 간 차이가 큼
- p < 0.05 → 적어도 어느 두 집단 간에 유의한 차이가 있음

> **ANOVA p < 0.05 → "어느 집단이 다른가?"는 알 수 없습니다.** 사후 검정 결과를 확인하세요.

**효과 크기**
- η² (Eta-squared) = 집단 간 SS / 전체 SS. 집단 요인이 종속 변수 분산의 몇 %를 설명하는지를 나타냅니다.

**사후 검정 (Post Hoc Tests)**

집단 간 유의한 차이가 있을 때, 어느 집단 쌍이 서로 다른지 파악합니다.

| 방법 | 특징 | 적합 상황 |
|------|------|-----------|
| **Tukey HSD** | 균형 잡힌 검정력과 보수성 | 등분산·동일 표본 크기 |
| **Bonferroni** | 단순·보수적 | 소수의 사전 계획 비교 |
| **Scheffe** | 가장 보수적 | 불균등 표본, 사후 탐색 비교 |

**레빈의 등분산 검정**
- p < 0.05 → 집단 간 분산이 다름 → **Welch ANOVA** 옵션을 추가로 확인하세요

---

## 7. 상관 및 회귀 분석

### 7.1 상관분석 (Correlation Analysis)

#### 언제 쓰나요?
두 연속형 변수가 얼마나 함께 변하는지 측정합니다.
- "학습 시간이 많을수록 성적이 높아지는가?"
- "나이와 혈압의 관계는?"

#### 상관계수의 종류

| 방법 | 언제 사용 |
|------|-----------|
| **피어슨(Pearson)** | 두 변수 모두 연속형이고 정규분포를 따를 때 (가장 일반적) |
| **스피어만(Spearman)** | 순서 척도이거나 정규성 가정이 충족되지 않을 때 |
| **켄달 타우(Kendall's τ)** | 소표본이거나 동순위(Ties)가 많을 때 |

#### 분석 수행 방법

1. **분석 > 상관(Correlate) > 이변량(Bivariate)** 선택
2. 분석할 변수 선택
3. 상관 유형 선택 (기본: Pearson)
4. **확인**

#### 결과 읽는 방법

**상관계수(r)의 해석**

| r 범위 | 해석 |
|--------|------|
| 0.9~1.0 | 매우 강한 양의 상관 |
| 0.7~0.9 | 강한 양의 상관 |
| 0.4~0.7 | 중간 양의 상관 |
| 0.1~0.4 | 약한 양의 상관 |
| ~0.1 | 상관 없음 |
| (음수는 음의 방향으로 대칭 해석) |

> **절대 주의**: 상관관계가 있다고 **인과관계가 성립하는 것은 아닙니다.**
> 예: 아이스크림 판매량과 익사 사고가 강한 양의 상관 → 아이스크림이 익사를 유발? (X) → 더운 날씨라는 공통 원인

---

### 7.2 선형 회귀 (Linear Regression)

#### 언제 쓰나요?
하나 이상의 예측 변수로 연속형 종속 변수를 예측합니다.
- "학습 시간과 수면 시간으로 성적을 예측할 수 있는가?"
- "면적, 층수, 역세권 여부로 아파트 가격을 예측하는 모형 구축"

#### 분석 수행 방법

1. **분석 > 회귀(Regression) > 선형(Linear)** 선택
2. **종속 변수** (예측하려는 변수, 연속형) 선택
3. **독립 변수** (예측에 사용할 변수) 선택
4. **확인**

#### 결과 읽는 방법

**모형 요약 (Model Summary)**

| 항목 | 해석 |
|------|------|
| **R** | 상관계수 (0~1) |
| **R²** | 모형 설명력. 종속 변수 분산의 몇 %를 설명하는지. 1에 가까울수록 좋음 |
| **수정 R²** | 변수 수를 보정한 R². 변수가 많을 때 더 정직한 지표 |

**ANOVA 표**: 회귀 모형 자체가 유의한지 F 검정으로 확인 (p < 0.05이면 모형이 유의)

**계수 표 (Coefficients)**

| 항목 | 해석 |
|------|------|
| **B (비표준화 계수)** | 독립 변수 1단위 증가 시 종속 변수 변화량. 단위가 있어 실질적 해석에 사용 |
| **Beta (표준화 계수)** | 표준화된 값. 변수 간 상대적 영향력 비교 시 사용 |
| **t, p-값** | 해당 예측 변수가 유의한지 |
| **VIF** | 다중공선성 지표. **10 초과 시 주의** (해당 변수를 제거하거나 결합 고려) |

> **예시 해석**: 학습 시간의 B = 5.2, p < 0.001 → "학습 시간이 1시간 증가하면 성적이 5.2점 상승하며, 이는 통계적으로 유의하다."

**잔차 분석 (Residual Diagnostics)**
- 더빈-왓슨(Durbin-Watson): 1.5~2.5 범위가 적절 (2에 가까울수록 자기상관 없음)

---

### 7.3 로지스틱 회귀 (Logistic Regression)

#### 언제 쓰나요?
종속 변수가 **이진형(예/아니오, 성공/실패)** 또는 범주형일 때 사용합니다.
- "이 고객이 이탈할 확률은?"
- "이 환자가 질병에 걸릴 가능성을 예측"

**분석 > 회귀 > 로지스틱** 메뉴에서 이항(Binary) 또는 다항(Multinomial)을 선택합니다.

#### 결과 읽는 방법

| 항목 | 해석 |
|------|------|
| **B** | 로그-오즈에 대한 영향. 해석이 직관적이지 않음 |
| **Exp(B) = 교차비(Odds Ratio)** | **가장 중요**. OR > 1이면 결과 발생 확률 증가, < 1이면 감소 |
| **95% CI for Exp(B)** | CI가 1을 포함하지 않으면 유의 |
| **호스머-레메쇼 검정** | p ≥ 0.05이면 모형이 데이터에 잘 맞음 (적합도) |
| **ROC AUC** | 모형의 판별력. 0.7 이상이면 양호 |

> **예시 해석**: 흡연의 OR = 3.2, 95% CI = [1.8, 5.7] → "흡연자는 비흡연자보다 해당 질환이 발생할 확률이 3.2배 높으며, 이는 통계적으로 유의하다."

---

## 8. 비모수 검정

#### 언제 쓰나요?
다음 상황 중 하나라도 해당하면 비모수 검정을 고려하세요.
- 표본 크기가 매우 작을 때 (n < 30)
- 정규성 검정 결과 p < 0.05일 때
- 순서 척도 변수를 비교할 때
- 극단적인 이상값이 있을 때

**분석 > 비모수 검정(Nonparametric Tests)** 메뉴를 사용합니다.

#### 모수 검정과의 대응 관계

| 비모수 검정 | 대응하는 모수 검정 | 상황 |
|------------|-------------------|------|
| **Mann-Whitney U** | 독립표본 t 검정 | 두 독립 집단 비교 |
| **Wilcoxon 부호순위** | 대응표본 t 검정 | 동일 개체 전후 비교 |
| **Kruskal-Wallis** | 일원분산분석 | 세 집단 이상 비교 |
| **Friedman** | 반복측정 ANOVA | 동일 개체 반복 측정 |

비모수 검정은 **순위(Rank)** 기반으로 작동하므로 극단값의 영향을 적게 받습니다. p < 0.05이면 집단 간 분포에 유의한 차이가 있다고 해석합니다.

## 9. 고급 분석

### 9.1 정규성 검정 (Normality Test)

#### 언제 쓰나요?
모수 검정(t 검정, ANOVA, 상관분석 등) 전에 데이터가 정규 분포를 따르는지 확인합니다.

**분석 > 기술통계량 > 탐색** 또는 **분석 > 비모수 검정 > 정규성 검정**을 이용합니다.

#### 결과 읽는 방법

| 검정 | 권장 표본 크기 | p-값 해석 |
|------|--------------|-----------|
| **Shapiro-Wilk** | n < 50 (소표본에 권장) | p ≥ 0.05: 정규성 충족 |
| **Kolmogorov-Smirnov** | n ≥ 50 (대표본) | p ≥ 0.05: 정규성 충족 |

> **실무 팁**: 표본이 크면 (n > 100 이상) 정규성 검정은 아주 작은 이탈도 유의하게 잡습니다. 이 경우 검정보다는 **히스토그램과 Q-Q 도표**를 시각적으로 확인하고, 왜도/첨도 값을 참고하세요.

---

### 9.2 요인분석 (Factor Analysis / PCA)

#### 언제 쓰나요?
- 여러 설문 문항이 공통으로 측정하는 잠재 요인을 찾을 때
- 변수 수를 줄일 때 (차원 축소)
- 척도의 구성 타당도를 검증할 때

**분석 > 차원 축소(Dimension Reduction) > 요인(Factor)** 메뉴를 선택합니다.

#### 결과 읽는 방법

**KMO 표본 적절성 측도**
- 0.9 이상: 훌륭함
- 0.7~0.9: 양호
- 0.6~0.7: 보통
- **0.6 미만: 요인분석 부적합**

**바틀렛 구형성 검정**: p < 0.05이어야 요인분석 가능

**요인 수 결정**
- 고유값(Eigenvalue) ≥ 1인 요인 선택이 기본 방법
- 스크리 도표(Scree Plot)에서 기울기가 급격히 완만해지는 지점 직전까지 선택

**요인 적재량 (Factor Loadings)**
- |적재량| ≥ 0.4: 해당 요인에 유의한 기여 (일반적 기준)
- |적재량| ≥ 0.3: 보수적 기준

**회전 방법**
- Varimax (직교 회전): 요인 간 상관이 없다고 가정. 해석이 단순. **가장 일반적**
- Oblimin (사각 회전): 요인 간 상관을 허용. 현실적으로 타당한 경우가 많음

---

### 9.3 군집분석 (Cluster Analysis)

#### 언제 쓰나요?
유사한 특성을 가진 개체를 자동으로 그룹화합니다.
- "우리 고객을 유사 행동 패턴으로 그룹화하면?"
- "지역별 특성에 따라 유사 지역을 묶으면?"

**분석 > 군집(Classify)** 메뉴를 사용합니다.

**K-평균 군집 (K-Means)**
- 사전에 군집 수(K)를 지정
- 최적 K 결정: 엘보우 도표(급격한 꺾임점)와 실루엣 계수(높을수록 좋음) 참고
- 결과: 군집 중심값, 각 군집 사례 수, ANOVA 표

**계층적 군집 (Hierarchical)**
- 사전 군집 수 불필요. 덴드로그램으로 구조 파악
- 연결 방법: Ward(가장 권장), Complete, Average
- 덴드로그램에서 적절한 높이에서 잘라 군집 수 결정

> **중요**: 군집분석 전에 변수를 표준화(Z-score)하세요. 단위가 다른 변수들이 혼합되면 큰 수치를 가진 변수가 군집을 지배합니다.

---

### 9.4 생존분석 (Survival Analysis)

#### 언제 쓰나요?
"어떤 사건이 언제 발생하는가"를 분석합니다.
- "환자들의 생존 기간 분석"
- "고객이 서비스를 해지하기까지 걸리는 기간"
- "장비가 고장나기까지의 시간"

**분석 > 생존분석(Survival)** 메뉴를 사용합니다.

**Kaplan-Meier 생존 곡선**
- 시간 변수와 사건 변수(0=중도절단, 1=사건발생) 지정
- 생존 함수 곡선: Y축(생존률), X축(시간)
- 곡선이 급격히 하강 = 그 시점에 사건 많이 발생
- 집단 비교: Log-rank 검정. p < 0.05이면 집단 간 생존 패턴이 다름

**Cox 비례위험 회귀**
- 여러 공변량이 사건 발생에 미치는 영향을 동시 분석
- 위험비(Hazard Ratio, HR): HR > 1이면 위험 증가, HR < 1이면 위험 감소
- 예: 흡연의 HR = 2.5 → "흡연자는 비흡연자보다 사망 위험이 2.5배"

---

### 9.5 판별분석 (Discriminant Analysis, LDA)

#### 언제 쓰나요?
여러 연속형 변수를 이용해 개체가 속한 집단을 분류하고, 집단 간 차이를 유발하는 변수를 파악합니다.
- "입학 시험 점수들로 합격/불합격을 예측"
- "재무 지표로 기업의 부도/정상을 분류"

**분석 > 군집 > 판별(Discriminant)** 메뉴를 사용합니다.

#### 결과 읽는 방법
- **윌크스 람다(Wilks' Lambda)**: 0에 가까울수록 판별력 높음
- **정준 상관**: 판별 함수와 집단 간 상관. 클수록 판별 효과 큼
- **분류 정확도**: 올바르게 분류된 비율. **75% 이상이면 실용적 수준**

---

### 9.6 편상관 (Partial Correlation)

#### 언제 쓰나요?
제3의 변수(혼란 변수)의 영향을 제거한 후, 두 변수 간의 순수한 관계를 측정합니다.
- "연령을 통제한 상태에서 운동량과 혈압의 관계는?"
- "소득 수준을 통제한 후 교육 연수와 건강 상태의 관계는?"

**분석 > 상관(Correlate) > 편상관(Partial)** 메뉴를 사용합니다.

이변량 상관 > 편상관이면 → 제3 변수가 두 변수의 관계를 매개 또는 혼란하고 있음을 시사합니다.

---

### 9.7 신뢰도 분석 (Reliability Analysis)

#### 언제 쓰나요?
설문 척도의 **내적 일관성**을 평가합니다. 여러 문항이 동일한 개념을 측정하는지 확인합니다.
- "리더십 척도 10개 문항이 실제로 같은 개념을 측정하는가?"

**분석 > 척도(Scale) > 신뢰도(Reliability)** 메뉴를 사용합니다.

#### 결과 읽는 방법 (Cronbach's α)

| α 값 | 해석 |
|------|------|
| α ≥ 0.9 | 매우 높음 |
| 0.7 ≤ α < 0.9 | 양호 (권장) |
| 0.6 ≤ α < 0.7 | 수용 가능 |
| α < 0.6 | 재검토 필요 |

**항목 제거 시 α**: 특정 문항을 제거했을 때 α가 크게 증가한다면, 그 문항이 척도의 일관성을 저해하는 것입니다 → 문항 제거 검토

**항목-전체 상관**: 0.3 미만이면 척도와 어울리지 않는 문항일 수 있습니다.

---

### 9.8 ROC 분석

#### 언제 쓰나요?
진단 검사 또는 예측 모형의 **변별력**을 평가합니다.
- "이 혈액 검사가 질병을 얼마나 정확히 탐지하는가?"
- "기계학습 모형의 분류 성능 평가"

**분석 > 진단 검정(Diagnostic) > ROC 분석** 메뉴를 사용합니다.

#### AUC (Area Under the Curve) 해석

| AUC | 판별력 |
|-----|--------|
| 0.9~1.0 | 우수 |
| 0.7~0.9 | 양호 |
| 0.5~0.7 | 불량 |
| 0.5 | 무작위 수준 (의미 없음) |

**최적 절단점(Optimal Cutoff)**: 민감도와 특이도의 합이 최대가 되는 임계값을 자동 탐색합니다.

---

### 9.9 민감도·특이도 분석

#### 이진 분류 성능 지표

| 지표 | 정의 | 높을수록 |
|------|------|---------|
| **민감도(Sensitivity, TPR)** | 실제 양성 중 양성으로 분류한 비율 | 놓치는 환자 적음 |
| **특이도(Specificity, TNR)** | 실제 음성 중 음성으로 분류한 비율 | 오탐 적음 |
| **양성예측도(PPV)** | 양성 판정 중 실제 양성인 비율 | 양성 판정의 신뢰도 |
| **음성예측도(NPV)** | 음성 판정 중 실제 음성인 비율 | 음성 판정의 신뢰도 |

> **트레이드오프**: 민감도를 높이면 특이도가 낮아집니다. 어느 쪽이 더 중요한지는 맥락에 따라 다릅니다. (예: 암 선별 검사 → 민감도 최대화)

---

### 9.10 일치도 분석 (Agreement Analysis)

두 평가자 또는 두 측정 방법 간의 일치도를 정량화합니다.

**Cohen's Kappa (κ)** — 범주형 변수

| κ | 일치도 |
|---|--------|
| ≥ 0.8 | 거의 완전 일치 |
| 0.6~0.8 | 상당한 일치 |
| 0.4~0.6 | 중간 일치 |
| < 0.4 | 낮은 일치 |

**ICC (Intraclass Correlation Coefficient)** — 연속형 변수
- ICC ≥ 0.75: 우수, 0.5~0.75: 중간, < 0.5: 낮음

**블랜드-알트만 도표**: 두 측정 방법의 일치 한계 시각화. 대부분의 점이 ±1.96×SD(95% 일치 한계) 내에 있으면 임상적으로 교환 가능한 수준으로 판단합니다.

---

### 9.11 카이제곱 적합도 검정

#### 언제 쓰나요?
관찰된 도수 분포가 이론적 분포와 일치하는지 검정합니다.
- "성별 비율이 50:50인가?"
- "주사위가 공정한가? (각 면이 1/6 확률)"

**분석 > 비모수 검정 > 카이제곱(Chi-Square)** 메뉴를 사용합니다.

결과표에 관찰 빈도, 기대 빈도, 잔차, χ² 통계량, 자유도, p값이 포함됩니다.

### 9.12 기계학습 (Machine Learning)

**분석 > 기계학습(Machine Learning)** 메뉴를 사용합니다.

| 알고리즘 | 유형 | 특징 |
|---------|------|------|
| 로지스틱 회귀 | 분류 | 계수 해석 가능, 기준 모형 |
| 의사결정나무 | 분류/회귀 | 규칙 시각화 용이 |

## 부록 A. 분석 기법 선택 가이드

### 종속 변수 유형으로 분류

**종속 변수가 연속형(척도)인 경우**

| 독립 변수 구성 | 권장 분석 |
|---------------|-----------|
| 없음 (분포 파악) | 기술통계량, 정규성 검정 |
| 범주형, 집단 2개 | 독립표본 t 검정 |
| 범주형, 집단 3개 이상 | 일원분산분석 (ANOVA) |
| 연속형 1개 | 단순 선형 회귀, 상관분석 |
| 연속형 여러 개 | 다중 선형 회귀 |
| 연속형 + 범주형 혼합 | 다중 선형 회귀 (공변량 포함) |

**종속 변수가 이진형(예/아니오)인 경우**

| 독립 변수 구성 | 권장 분석 |
|---------------|-----------|
| 범주형 1개 | 교차분석 (카이제곱) |
| 연속형/혼합 | 이항 로지스틱 회귀 |
| 예측 정확도 평가 | ROC 분석, 민감도·특이도 |

**종속 변수가 순서형인 경우**

- 비모수 검정 (Mann-Whitney U, Kruskal-Wallis 등) 권장

**종속 변수가 시간(생존 시간)인 경우**

- Kaplan-Meier 생존 곡선, Cox 회귀

### 상황별 빠른 선택표

| 분석 목적 | 권장 분석 |
|-----------|-----------|
| 범주형 변수 분포 파악 | 빈도분석 |
| 연속형 변수 기초 통계 | 기술통계량 |
| 두 범주형 변수 간 관계 | 교차분석 (카이제곱) |
| 한 집단 평균을 기준값과 비교 | 단일표본 t 검정 |
| 두 독립 집단 평균 비교 | 독립표본 t 검정 |
| 동일 개체 전·후 비교 | 대응표본 t 검정 |
| 세 집단 이상 평균 비교 | 일원분산분석 |
| 연속형 변수 간 관계 측정 | 상관분석 |

## 부록 B. 결과 보고 작성 예시

### B.1 독립표본 t 검정 보고 예시

> 남성(M = 75.3, SD = 8.2, n = 45)과 여성(M = 71.8, SD = 9.1, n = 48)의 시험 점수를 비교한 결과, 두 집단 간 유의한 차이가 있는 것으로 나타났다, t(89.3) = 2.01, p = .047, d = 0.41. 남성의 점수가 여성보다 평균 3.5점 높았으며, 95% CI = [0.04, 6.96].

### B.2 일원분산분석 보고 예시

> 세 지역(A, B, C) 간 평균 소득을 비교한 일원분산분석 결과, 집단 간 유의한 차이가 있었다, F(2, 147) = 8.43, p < .001, η² = 0.103. Tukey HSD 사후 검정 결과, A 지역(M = 350만 원)과 C 지역(M = 410만 원) 간에 유의한 차이가 있었다(p = .002).

### B.3 상관분석 보고 예시

> 학습 시간과 시험 점수 간에 유의한 정적 상관관계가 있었다, r = .62, p < .001. 이는 학습 시간이 증가할수록 시험 점수도 높아지는 경향이 있음을 나타낸다.

### B.4 선형 회귀 보고 예시

> 학습 시간과 수면 시간을 예측 변수로 한 선형 회귀 분석 결과, 회귀 모형은 유의하였으며, F(2, 97) = 23.4, p < .001, R² = .325. 학습 시간(β = .52, p < .001)은 성적을 유의하게 예측하였으나, 수면 시간(β = .12, p = .184)은 유의하지 않았다.

## 부록 C. 통계 용어 해설

| 용어 | 설명 |
|------|------|
| **평균(Mean)** | 모든 값의 합을 개수로 나눈 값. 극단값에 민감 |
| **중앙값(Median)** | 순서대로 정렬했을 때 가운데 위치한 값. 극단값에 강건 |
| **최빈값(Mode)** | 가장 많이 나타나는 값 |
| **분산(Variance)** | 관측값이 평균에서 얼마나 퍼져 있는지 측정. 표준편차의 제곱 |
| **표준편차(SD)** | 평균으로부터의 평균 거리. 분산의 제곱근 |
| **표준오차(SE)** | 표본 평균이 모집단 평균에서 얼마나 벗어날 수 있는지. SE = SD/√n |
| **신뢰 구간(CI)** | 모집단 모수가 포함될 것으로 추정되는 범위. 95% CI가 일반적 |
| **p-값** | 귀무가설이 참일 때 관측된 결과 이상의 극단적 결과가 나올 확률 |
| **귀무가설(H₀)** | "차이가 없다", "효과가 없다"는 기본 가설 |
| **대립가설(H₁)** | 연구자가 증명하려는 가설. "차이가 있다" |
| **1종 오류(α)** | 귀무가설이 참인데 기각하는 오류 (거짓 양성). 유의수준으로 통제 |
| **2종 오류(β)** | 귀무가설이 거짓인데 채택하는 오류 (거짓 음성) |
| **검정력(Power)** | 실제 효과가 있을 때 이를 탐지할 확률. 1 - β. 0.8 이상 권장 |
| **자유도(df)** | 통계량 계산에 사용 가능한 독립적인 정보의 수 |
| **정규분포** | 평균을 중심으로 좌우 대칭인 종 모양 분포 |
| **왜도(Skewness)** | 분포의 비대칭성. +이면 오른쪽 꼬리, -이면 왼쪽 꼬리 |
| **첨도(Kurtosis)** | 분포의 뾰족한 정도. 정규분포는 0(초과 첨도 기준) |
| **이상값(Outlier)** | 대부분의 값에서 크게 벗어난 관측값 |
| **결측값(Missing)** | 측정되지 않았거나 기록되지 않은 값 |
| **효과 크기** | 통계적 차이나 관련성의 실질적 크기. p-값과 별개 |
| **모집단** | 연구 대상이 되는 전체 집합 |
| **표본** | 모집단에서 선택된 일부 |
| **무작위 표집** | 편향 없이 표본을 추출하는 방법. 일반화 가능성 높음 |
| **다중공선성** | 여러 독립 변수가 서로 높은 상관관계를 가지는 현상. 회귀 계수 불안정 |
| **교차비(OR)** | 한 집단이 다른 집단 대비 특정 결과가 나타날 확률의 비 |
| **위험비(HR)** | 생존분석에서 사건 발생 위험의 집단 간 비율 |
| **공변량(Covariate)** | 통제하고자 하는 제3의 변수 |
| **혼란 변수** | 두 변수의 관계에 영향을 주는 제3의 변수 |
| **내적 일관성** | 여러 문항이 동일한 개념을 측정하는 정도 |
| **타당도** | 측정 도구가 측정하려는 것을 실제로 측정하는 정도 |
| **신뢰도** | 동일한 측정을 반복했을 때 일관된 결과가 나오는 정도 |

## 부록 D. 자주 묻는 질문 (FAQ)

**Q. 결과에서 p = .000으로 나옵니다. 이게 p = 0이라는 뜻인가요?**

A. 아닙니다. 소수점 세 자리에서 반올림한 표현으로, "p < 0.0005"를 의미합니다. 보고서에는 `p < .001`로 표기하는 것이 표준입니다.

---

**Q. 표본 크기가 작은데 어떤 분석을 써야 하나요?**

A. 표본이 30 미만이면 정규성 가정 충족이 어렵습니다. 비모수 검정(Mann-Whitney, Wilcoxon 등)을 우선 고려하세요. Shapiro-Wilk 정규성 검정 결과가 p ≥ 0.05이면 모수 검정도 사용 가능합니다.

---

**Q. 분석에서 변수가 선택 목록에 보이지 않습니다.**

A. 분석 대화 상자의 변수 목록은 해당 분석에 적합한 척도 유형만 표시합니다. 변수 뷰에서 척도 설정이 올바른지 확인하세요. 예를 들어, 기술통계량에는 **척도(Scale)** 변수만 나타납니다.

---

**Q. 상관분석에서 r = 0.85인데 p = .234로 유의하지 않습니다. 어떻게 된 건가요?**

A. 표본 크기가 매우 작을 때 발생합니다. p-값은 표본 크기에 크게 영향을 받습니다. 표본이 n=5이면 강한 상관도 유의하지 않을 수 있습니다. 이 경우 표본 크기를 늘리거나, 결과를 해석할 때 "표본 크기 제한으로 인해 통계적 유의성을 입증하기 어려웠으나 관련성의 방향과 크기는 시사적이다"와 같이 맥락을 설명하세요.

---

**Q. 프로젝트(.swb)를 저장했는데 다시 열면 분석 결과가 없습니다.**

A. .swb 형식은 데이터와 변수 설정만 저장합니다. 분석 결과는 HTML로 별도 내보내기 하거나, 구문 로그를 저장하여 재실행하는 방식으로 보존하세요.

---

**Q. 엑셀 파일을 가져왔는데 한글이 깨집니다.**

A. 가져오기 대화 상자에서 인코딩을 **UTF-8** 또는 **CP949**로 수동 지정하세요. .xlsx 파일은 일반적으로 인코딩 문제가 없으므로 .csv 대신 .xlsx를 권장합니다.

---

**Q. ANOVA 결과는 유의한데, 사후 검정에서 어느 쌍도 유의하지 않습니다.**

A. 사후 검정은 ANOVA보다 보수적이어서 이런 상황이 발생할 수 있습니다. Tukey 대신 덜 보수적인 **LSD(Least Significant Difference)** 방법을 사용하거나, 표본 크기를 늘리는 것을 고려하세요. 또는 Bonferroni 보정 없이 개별 t 검정으로 탐색적으로 확인해 볼 수도 있습니다 (단, 이 경우 1종 오류 증가를 인지해야 함).

---

**Q. 회귀분석에서 VIF가 10을 초과하는 변수가 있습니다. 어떻게 처리하나요?**

A. 다중공선성이 의심됩니다. 다음 방법을 고려하세요.
1. 상관이 높은 변수 중 하나를 제거
2. 두 변수를 합산하거나 평균으로 결합
3. 주성분 분석(PCA)으로 변수 수를 줄인 후 회귀
4. Ridge 회귀 등 정규화 방법 사용
