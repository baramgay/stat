# NuriStat 실행 방법

## 1. WSL에서 GUI 실행 (X Server 필요)

WSL은 기본적으로 GUI를 지원하지 않으므로 X Server가 필요합니다.

### 1.1 Windows에 X Server 설치

**VcXsrv (권장)**
1. https://sourceforge.net/projects/vcxsrv/ 에서 다운로드
2. 설치 후 "XLaunch" 실행
3. 설정:
   - Display number: 0
   - Multiple windows
   - Start no client
   - **Extra settings에서 "Disable access control" 체크** (중요)

**Windows 11 내장 WSLg (Windows 11 22H2+)**
- Windows 11 최신 버전이라면 별도 설치 없이 GUI 지원
- `wsl --update` 로 WSL 최신화

### 1.2 WSL에서 DISPLAY 설정

```bash
# VcXsrv 사용 시
export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2}'):0

# 또는 Windows 11 WSLg 사용 시 (자동 설정됨)
echo $DISPLAY
# 출력: :0
```

영구 설정:
```bash
echo 'export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk \'{print $2}\'):0' >> ~/.bashrc
source ~/.bashrc
```

### 1.3 NuriStat 실행

```bash
# 프로젝트 디렉토리로 이동
cd /mnt/c/업무/통계패키지/nuristat

# 방법 1: Python 모듈로 실행
python3 -m nuristat.main

# 방법 2: pip 설치 후 실행
pip install -e .
nuristat

# 방법 3: 직접 실행
PYTHONPATH=src python3 src/nuristat/main.py
```

## 2. Windows에서 직접 실행 (권장)

WSL 없이 Windows Python에서 실행하는 것이 더 안정적입니다.

### 2.1 Windows Python 설치

1. https://python.org 에서 Python 3.11+ 다운로드
2. 설치 시 "Add Python to PATH" 체크

### 2.2 의존성 설치

```cmd
# CMD 또는 PowerShell
cd C:\업무\통계패키지\nuristat

pip install PySide6 pandas numpy scipy statsmodels openpyxl pydantic pytest tabulate
```

### 2.3 실행

```cmd
# 방법 1: 모듈로 실행
python -m nuristat.main

# 방법 2: 직접 실행
python src/nuristat/main.py
```

---

## 3. PyInstaller 실행 파일 생성

배포용 실행 파일(.exe)을 만드는 방법입니다.

### 3.1 PyInstaller 설치

```bash
pip install pyinstaller
```

### 3.2 실행 파일 빌드

```bash
cd /mnt/c/업무/통계패키지/nuristat

# 단일 실행 파일 생성
pyinstaller --onefile --windowed \
  --name NuriStat \
  --add-data "src/nuristat/ui/theme.py:nuristat/ui" \
  --add-data "src/nuristat/ui/icons.py:nuristat/ui" \
  src/nuristat/main.py

# 출력: dist/NuriStat.exe
```

## 4. 테스트 실행 (CLI)

GUI 없이 테스트만 실행하려면:

```bash
cd /mnt/c/업무/통계패키지/nuristat

# 전체 테스트
python3 -m pytest tests/ -v

# 특정 모듈 테스트
python3 -m pytest tests/core/ -v
python3 -m pytest tests/analysis/ -v
python3 -m pytest tests/test_io/ -v
python3 -m pytest tests/ui/ -v

# 빠른 테스트 (요약만)
python3 -m pytest tests/ -q
```

## 5. 문제 해결

### Q: `qt.qpa.xcb: could not connect to display` 오류
A: X Server가 실행 중인지, DISPLAY 환경변수가 올바른지 확인

### Q: `ModuleNotFoundError: No module named 'nuristat'`
A: PYTHONPATH 설정 또는 `pip install -e .` 실행

### Q: 한글 깨짐
A: 폰트 설정 확인. theme.py에서 `font-family: 'Malgun Gothic', ...` 설정됨

### Q: 테스트 실패
A: 의존성 설치 확인: `pip install -e '.[dev]'`
